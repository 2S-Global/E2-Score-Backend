# Code Change Policy

NEVER change existing code without my explicit consent.

Before changing any existing file:

- Explain what you want to change.
- Tell me which files will be changed.
- Explain why the change is needed.
- Show the proposed changes/diff when possible.
- WAIT for my explicit approval.

Do not:

- Modify existing files without approval.
- Delete files without approval.
- Rename files without approval.
- Refactor without approval.
- Update dependencies without approval.
- Change configuration without approval.
- Run destructive commands without approval.

You may inspect and analyze the project without changing anything.

If you are unsure whether an action changes the project, STOP and ask me first.
